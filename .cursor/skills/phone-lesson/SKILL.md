# 手機上課

學生在手機上看 Cursor 對話，看不到編輯器。

**Canonical：** 本檔（專案 `.cursor/skills/phone-lesson`）。

## 一定要做

- 講到某個檔案、或剛改完檔案：立刻把**當時完整內容**貼在對話的 markdown 程式碼塊裡
- 標路徑一行即可，不要叫學生「去 IDE 看」
- 說明要短：一行一件事，方便小螢幕

## 與 course-teacher

- 手機模式仍遵守 `course-teacher`（或該課改名後的 teacher）：一次一題、短題面
- 貼碼＝當題相關檔，不要貼整章講義或題 1～N 清單
- 出題格式以 teacher skill 為主；本 skill 只負責把該檔貼出來

## 代打

- 學生說「你寫」：直接改檔、跑測試，再把結果檔案貼上來
- 不要假設學生能自己打字或看紅燈視窗
